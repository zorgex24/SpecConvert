Независимый счетчик интеграционных тестов считает физические непустые ячейки BO
в исследованных исходниках вне заголовка/штампа. Рабочий парсер определяет графу
по тексту заголовка, не используя эту координату.

Сопоставлены исходные значения и экспорт для следующих фрагментов:

- РП: наименование из четырех строк, тип из трех строк, одно количество.
- ШУ1 / ШУ3: одна запись с обоими обозначениями и полным многострочным описанием.
- Стойка металлическая: семь вариантов, МШП1-10-120 наследует «шт.», пустая масса сохранена.
- Фиксатор: исполнения с листа 4 получают общий текст с листа 3.
- Комплект ОПН: два исполнения с общим наименованием и собственными количествами 9 и 5.
- Контрольный кабель: оба сечения сохраняют полное общее описание.
- Общая комплектация подстанции и заголовок кабелей отделены от предыдущих изделий.

Экспорт повторно открыт через ClosedXML; проверены число строк, тип количества,
пустая масса, порядок разделов, девять столбцов и отсутствие объединений.
Проверены заблокированный выходной файл и поврежденный исходник. Исправлена утечка
файлового дескриптора при исключении конструктора книги.

WPF проверен автоматическим STA-тестом загрузки XAML и записи ручной правки
через привязку столбца DataGrid. Полная ручная визуальная приемка интерфейса и
печатного оформления Excel не проводилась. Проверка семантики всех 160 позиций
человеком остается необходимой для окончательной приемки, особенно предупреждений.

Ограничения алгоритма описаны в README. Совпадение счетчиков не доказывает
безошибочность распределения каждого фрагмента текста между исполнениями.
